# The 1.44 MB Feature for CP/M-86

This software makes "CP/M-86 for the IBM PC and IBM PC XT  Version 1.1"
support diskettes with much higher capacities than the old, standard CP/M-86
160 KB and 320 KB formats. Now, you can store:

- up to 710 KB of data on a 3.5 inch, 720 KB diskette
- up to 1.18 MB of data on a 5.25 inch, 1.2 MB diskette
- up to 1.42 MB of data on a 3.5 inch, 1.44 MB diskette.


## Program 144PAT.CMD

After running the driver program 144PAT.CMD from the CP/M-86 command prompt,
your CP/M-86 version 1.1 system can use 720 KB, 1.44 MB and 1.2 MB diskettes
for storing up to 710 KB c.q. 1.42 MB c.q. 1.18 MB of data.
The driver also allows you to read from and write to 720 KB (netto 702 KB)
diskettes that have been created by "Personal CP/M-86 Plus version 2.0/4".

144PAT.CMD only modifies the code of CP/M-86 that is currently loaded into
the RAM memory of your system, it does NOT make any changes to the CP/M-86
software on your harddisk or diskette. So, after each reboot of your system
you might want to re-run 144PAT.CMD.

Before you can use a 720 KB, 1.44 MB or 1.2 MB diskette with CP/M-86, the 
diskette must have been prepared ("formatted") with the program 144PREP2.CMD
or 144PREP2.COM.

## What you need

1. An IBM or IBM-compatible PC with at least 64 KB of memory.

2. A diskette drive that supports the diskette types (720 KB, 1.2 MB, 1.44 MB)
   that you want to use.

3. CP/M-86 version 1.1 for the IBM PC and PC/XT, with at least 9 KB of FIDD
   memory configured (see below)

4. 720 KB, 1.44 MB or 1.2 MB diskettes

5. companion program 144PREP2 to prepare 720 KB, 1.44 MB or 1.2 MB 
   diskettes for use with CP/M-86.

## FIDD memory

In their version 1.1 of CP/M-86 for the IBM PC and XT, Digital Research added a
way to reserve from 0 to 99 KB of the RAM memory in the PC for use by so-called
"Field Installable Device Drivers" or FIDD programs. 
The 1.44 Mb Feature program 144PAT.CMD, although not a true FIDD program, 
needs 9 KB of this FIDD memory.

To reserve this (or a larger) amount of FIDD storage you should use the 
program SETUP.CMD that is part of the CP/M-86 version 1.1 distribution:

- Start the SETUP program
- press function key F5 "Field Inst. Device Driver" to change the amount of
  FIDD memory, and follow the instructions on the screen. 

Upon exit from the SETUP program, press the appropriate function key to
write the settings to your harddisk (when CP/M-86 was booted from that
harddisk) or to a diskette in drive A:. In the latter case, be sure to put
your CP/M-86 boot diskette in drive A: before committing the changes to disk.

Finally, reboot your CP/M-86 system to activate the new FIDD settings. During
a boot, CP/M-86 will tell you how much FIDD memory is available.


## Running 144PAT.CMD

Syntax:

```
	144PAT <options>

<options>

	are used to control the amount of diagnostic output the program
	will write to the console screen

```

## 144PAT.CMD command line options

	V

	is an abbreviation for "verbose". This option will cause 144PAT.CMD
	to display the results of all checks it is performing before making
	any changes ("patches") to your running CP/M-86 system. If you do not
        specify this options, only a few lines of output will be produced.

	If you have any trouble running 144PAT.CMD, use this Verbose
        option to get more information for problem determination.

	3

	specifies that you will be using the 1.2 MB format on 1.44 MB, 3.5 inch
        media instead of the usual 5.25 inch high capacity media.
        This option is only useful if you want to test 1.2 MB support on a PC
        without a real 5.25 inch diskette drive.

	If you do not specify this option, 144PAT.CMD will assume that
        diskettes with 1.2 MB capacity are 5.25 inch diskettes (the program
        is not capable of determining the actual diskette drive type that's
        in your PC).


## Usage notes about 144PAT.CMD

1. 144PAT.CMD needs to reset all disk drives, when it loads. This causes
   CP/M-86 to log-in your boot drive. So there must be a valid 160 KB or 320
   KB diskette in your boot drive, if you started CP/M-86 from a diskette.

2. There might exist CP/M-86 utilities that can "redirect" the output of a
   program to a disk file. You are advised, not to run 144PAT.CMD while any
   such utility is active.

   If you need to review the output of 144PAT.CMD, you can activate the
   standard CP/M-86 printer echo by pressing control-P before running 
   144PAT.CMD.

3. Do not forget to press a control-C at the CP/M-86 command prompt, every time
   you have changed diskettes!

   CP/M-86 can, by itself, detect a diskette change and it will put the new
   diskette in read-only status. But it will only re-calculate the free space
   and recognize the format of the new diskette if you press a control-C. If
   you don't, CP/M-86 will blindly assume that the new diskette has exactly
   the same format as the previous diskette in the drive.

   Pressing control-C after a diskette change is a standard, documented
   CP/M-86 requirement. To prevent CP/M-86 from crashing, strictly follow this
   requirement - especially when you change from one diskette format to 
   another.

   If a DIR command shows multiple entries with the same names, or if you get
   the message "MEMORY NOT AVAILABLE" after you typed the name of an external
   command: then you probably have forgotten to press control-C after you
   changed a diskette.
